# Contributing

Use Python 3.12 and an isolated virtual environment. Install the development
dependencies documented in the README and run `python -m pytest -q` before opening
a pull request. Add a regression test when fixing a behavioral bug.

Keep examples synthetic and small. Do not commit competition data, credentials,
trained weights, virtual environments, or generated artifacts. Preserve source
attribution and document any new dependency's purpose. Changes to legacy research
code should state which dataset and environment were actually tested.
